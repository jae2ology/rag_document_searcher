# AI-Powered Document Search using RAG (Retrieval Augmented Generation) with Ollama LLM API

### A personal web portal where you drop in a set of PDFs (e.g., a 300-page manual or textbook) and ask natural language questions to get exact answers with page citations.

## ⚡ Key Features

* **Semantic Vector Search:** Uses vector embeddings to search by *meaning* rather than rigid keyword matches.
* **Retrieval-Augmented Generation (RAG):** LLM responses use extracted chunks from your uploaded documents to minimize hallucinations.
* **Source Citations:** Every answer references exact page numbers and context snippets for verification.
* **Smart PDF Chunking:** Uses recursive character splitting with overlap to maintain semantic continuity across section breaks.
